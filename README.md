# Accessibility Bookmarklet

This project is a JavaScript-based accessibility bookmarklet that provides various features to enhance web accessibility. Users can activate the bookmarklet to apply accessibility improvements to any webpage.

## Features

- **High Contrast Mode**: Inverts colors for better visibility.
- **Grayscale Mode**: Converts the page to grayscale for colorblind users.
- **Font Change**: Replaces fonts with a more readable alternative.
- **Text-to-Speech**: Adds a microphone icon next to text elements, allowing users to click and hear the text read aloud.

## How to Use

1. Copy the code from `index.js`.
2. Create a new bookmark in your browser.
3. Paste the code into the URL field of the bookmark, prefixed with `javascript:`.
